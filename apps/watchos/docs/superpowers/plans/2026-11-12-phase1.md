# Charlie WatchOS Phase 1 Implementation Plan

Goal: A working Windows smartwatch simulator, without physical watch assumptions.
Architecture: Five crates; dependency-free no_std state machine; no_std serde protocol; explicit HAL traits; Slint presentation; Windows desktop integration.
Tech: Rust 1.99.1, Slint 1.18.1, software renderer, Cargo.lock.
Spec: Owner Phase 1 request in this chat.

## Scope and decisions
Only this project changes. No hardware work, Android modification, server access, telemetry, fake readings, Embassy desktop dependency, or firmware claim. Existing references inspected read-only. Choose single-threaded event dispatch over async runtime: no live transport exists yet. Settings file uses explicit storage interface; malformed data fails safely with visible warning. Connection remains Unavailable until adapter exists.
